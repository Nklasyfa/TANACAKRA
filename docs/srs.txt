1. Introduction 
1.1 Purpose 
Dokumen ini mendefinisikan kebutuhan perangkat lunak ( Software Requirements 
Specification/SRS) untuk TANACAKRA: End -to-End Pipeline Data Science Python Berbasis 
Web untuk Pendukung Keputusan Pengelolaan Lahan Pertanian. SRS ini menjadi acuan utama 
untuk perancangan, implementasi, pengujian, dan deployment dalam proyek 
1.2 Scope 
Sistem Tanacakra menyediakan antarmuka pengguna interaktif untuk analisis data dan keputusan 
pengelolaan lahan pertanian berbasis Machine Learning. Sistem mencakup pemrosesan Data 
Science Pipeline , visualisasi data interaktif, manajemen hak akses berbasis role (Admin & 
Pengguna), integrasi API, serta pemantauan log aktivitas. 
1.3 Product Overview 
Jenis pengguna utama: Petani dan Admin/Kelompok Tani/Penyuluh (2 Role). 
Platform: 
Web Frontend (Vue) + Backend REST API (Django). Database & Auth menggunakan Supabase 
(PostgreSQL). Data Science Engine: Scikit-learn (Python). Data Visualization: Plotly. API Testing 
/ Integration: Postman / Antigravity. Deployment.

2. Overall Description 
2.1 Product Perspective 
Sistem Tanacakra dibangun secara modular ( greenfield) dengan arsitektur terpisah ( decoupled 
architecture), di mana frontend Vue berkomunikasi melalui REST API dengan backend Django 
yang terintegrasi dengan Supabase (PostgreSQL & Auth) serta pipeline Python (Scikit-learn) dan 
Plotly. 
2.2 Product Functions (High-Level) 
a. Autentikasi pengguna dan otorisasi hak akses (RBAC) via Supabase Auth untuk Petani dan 
Admin/Kelompok Tani/Penyuluh. 
b. Manajemen master data lahan dan konfigurasi pipeline oleh Admin/Kelompok 
Tani/Penyuluh. 
c. Input parameter lahan dan eksekusi Data Science Pipeline (Scikit-learn) oleh Petani 
d. Visualisasi grafik dan dasbor keputusan interaktif menggunakan Plotly.  
e. Pengujian dan eksekusi skenario API endpoint melalui integrasi Postman / Antigravity.  
f. Dashboard analitik dan pemantauan aktivitas system.

2.4 Operating Environment 
Frontend: Vue (JavaScript/TypeScript). 
Backend: Django (Python Runtime). 
Database/Auth: Supabase (PostgreSQL) 
Data Science & Analytics: Scikit-learn & Plotly Library. 
Deployment Environment: - 
API Client & Integration Testing: Postman / Antigravity. 
Browser Target: Chrome/Firefox/Edge versi modern. 
2.5 Design and Implementation Constraints 
a. Komunikasi antara Vue dan Django wajib menggunakan standar RESTful API 
b. Database dan otentikasi pengguna wajib menggunakan Supabase (PostgreSQL). 
c. Seluruh pemrosesan model Data Science  wajib menggunakan pustaka Scikit -learn 
(Python). 
d. Visualisasi data dan rekomendasi pada Vue wajib me-render objek interaktif Plotly. 
e. Manajemen tugas tim dan tracking progress wajib dikelola sepenuhnya melalui ClickUp. 
f. Pengujian API harus dapat tereksekusi dan tervalidasi menggunakan Postman / 
Antigravity. 
2.6 Assumptions and Dependencies 
a. Backend Django dan Data Science Pipeline berjalan pada infrastruktur lingkungan yang 
mendukung dependensi Python dan koneksi ke Supabase. 
b. Koneksi jaringan stabil antara client Vue, backend Django, dan cloud Supabase saat 
transmisi data. 
3. Functional Requirements 
FR-01 - User Authentication (Supabase): 
Sistem shall menyediakan fungsi Login dan Register via Supabase Auth untuk Petani dan 
Admin/Kelompok Tani/Penyuluh. 
Aktor terkait: Semua 
Prioritas: Must 

FR-02 - Role-Based Access Control (RBAC): 
Sistem shall membatasi akses fitur dan API sesuai hak akses Petani atau Admin/Kelompok 
Tani/Penyuluh. 
Aktor terkait: Semua 
Prioritas: Must 
FR-03 - Land Data Management: 
Admin/Kelompok Tani/Penyuluh shall dapat mengelola master data lahan dan variabel input 
sistem di Supabase via Django 
Aktor terkait: Semua 
Prioritas: Must 
FR-04 - Parameter Input: 
Petani shall dapat memasukkan data parameter lahan melalui antarmuka Vue untuk diproses oleh 
pipeline. 
Aktor terkait: Petani 
Prioritas: Must 
FR-05 - Data Science Pipeline Execution 
Sistem shall memproses data input lahan menggunakan model Scikit-learn di backend Django.  
Aktor terkait: System 
Prioritas: Must 
FR-06 - Decision Support Visualization: 
Sistem shall menampilkan hasil analisis dan rekomendasi pengelolaan lahan dalam bentuk grafik 
interaktif menggunakan Plotly pada frontend Vue. 
Aktor terkait: Semua 
Prioritas: Must 
FR-07 - API Endpoint Execution: 
Sistem shall menyediakan REST API endpoint yang kompatibel ditembak/diuji via Postman / 
Antigravity. 
Aktor terkait: Admin/System 

Prioritas: Must 
FR-08 - System Activity Logging: 
Sistem shall mencatat riwayat pemrosesan data dan log kesalahan ke audit log Supabase/Django.  
Aktor terkait: System 
Prioritas: Must 
4. Non-Functional Requirements 
NFR-01 Security 
Sandi dan otentikasi dikelola oleh Supabase Auth; endpoint terproteksi dengan token RLS ( Row 
Level Security)/JWT.  
NFR-02 Performance 
Respon API pemrosesan ringan dan visualisasi Plotly should dirender < 3 detik 
NFR-03 Maintainability 
Struktur kode frontend (Vue) dan backend (Django) harus modular dan terpisah. 
NFR-04 Compatibility 
Antarmuka Vue mendukung browser modern (Chrome, Firefox, Edge). 
NFR-05 API Testing Readiness 
Endpoint REST API harus terdokumentasi dan dapat diproses secara langsung melalui koleksi 
Postman / Antigravity. 
5. Business Rules 
1. BR-01: Hanya akun berpangkat Admin / Kelompok Tani / Penyuluh yang diizinkan 
mengonfigurasi parameter Data Science Pipeline dan data lahan utama.  
2. BR-02: Petani hanya dapat melihat dan mengolah data lahan milik sendiri atau data umum 
yang disajikan oleh sistem 
3. BR-03: Pemrosesan prediksi Scikit -learn hanya dieksekusi jika parameter input lahan 
memenuhi validasi skema API. 
4. BR-04: Setiap interaksi API harus tervalidasi menggunakan token autentikasi Supabase yang 
sah. 
6. Use Case Specification 
UC-01 - Login 
Primary Actor: Semua user 

Preconditions: : User masuk ke antarmuka sesuai perannya. 
Main Flow 
1. User membuka halaman login pada Vue. 
2. User memasukkan kredensial dan menekan tombol Submit.  
3. Supabase Auth memvalidasi kredensial dan mengembalikan token otentikasi. 
4. Sistem mengarahkan user ke dashboard sesuai hak akses (Petani / Admin/Kelompok 
Tani/Penyuluh). 
UC-02 - Run Land Analytics & Plotly Visualization 
Primary Actor: Petani 
Preconditions: Petani telah berhasil login. 
Trigger: Customer memilih menu booking. 
Main Flow 
1. Petani menginput parameter kondisi lahan pada form Vue.  
2. Vue mengirimkan request payload ke REST API Django 
3. Django memanggil pipeline Scikit-learn untuk memproses prediksi/rekomendasi. 
4. Django/Supabase mengembalikan format JSON data visualisasi ke Vue. 
5. Antarmuka Vue menampilkan dasbor rekomendasi dan grafik Plotly secara interaktif.  
Postconditions: Hasil analisis Scikit-learn dan chart Plotly berhasil ditampilkan.
